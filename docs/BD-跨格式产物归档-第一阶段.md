# Xuan BD 跨格式产物归档与本地保留策略（第一阶段）

## 已接入的能力

- `artifact.archive`（跨格式产物归档工具）已登记为 BD Direct（确定性受控工具），供 BD AGENTS 在**明确授权的任务调用**中使用。
- 只接受 `sourceTaskId`（原成功任务编号）和该任务结果 `artifactIds`（已发布文件引用清单）中存在的 `fileRefId`（文件引用编号）；不接受本地路径、任意 URL 或自定义网盘命令。
- 允许来自网页、接口、网站采集、音视频转写、文档转换等**已发布生成文件**的统一归档，不修改既有格式解析器。
- 目的地由 `topic`（已登记的金融证据主题）和 `purpose`（来源原件/加工证据/交接回执）选择；继续复用 `CloudCustodyBackend`（百度网盘存证后端）与 `runBaiduSkillCommand`（网盘 Skill 统一命令执行器），不另造命令行。
- 原文件经单件 SHA-256（本地内容摘要）核对，上传前在 `artifact_archive_receipts`（跨格式归档回执账本）冻结原任务、文件版本、摘要、目标和账号绑定。
- 远端按文件名、长度和 `fs_id`（远端对象编号）核对。不下载读回，不声称网盘实际字节已通过本地 SHA-256 验证。
- 上传返回未知时冻结同一目标；后续明确重发 `artifact.archive` 只能只读检查原目标，不能再次上传、改名或自动清理。原来源任务和本地文件不受影响。

## 本轮尚未启动的删除操作

本轮**没有**修改或删除 `material_objects`（原件记录与共享内容对象）、`candidate_objects`（五步加工候选对象）、R1（正式入库交接）、`conversion_artifacts`（转换产物账本）以及 WFD（金融数据仓库）正式数据。

原因：`FileReferenceService`（本地文件引用服务）仍按真实本机路径及对象身份核对，若归档后直接删除，原有 `readBytes`（有权限的原件读取）和已登记的 R1/检索任务将失败。当前只有“网盘存证 + 本地引用不变”，**尚未完成远端恢复代替本地引用**。不能将成功上传当作安全回收的授权。

## 不同源的后续处理建议（不是已实现功能）

| 来源 | 归档候选 | 本地长期目标 | 尚缺条件 |
|---|---|---|---|
| 视频链接 / 音频 | 字幕及带时间戳的转写证据，必要画面证据 | URL、视频 ID、业务时间定位、正式 WFD 数据；转换用音轨非长期产物 | 消费端引用转移和按需恢复 |
| 网页、公告、社交内容 | 原始响应与必要的正文/版本证据 | 来源身份、采集时间、提取结果引用 | DOM/正文重复判定、下游引用验证 |
| API / 行情 / 财务 | 原始响应、首次/修订版本及必要回执 | 结构化 WFD 行、快照、来源及定义关系 | R1 固定读回后检测未使用副本 |
| PDF、Office、表格、图片 | 原件、必要页码/坐标/原值证据 | 正式 WFD 数据和轻量引用 | OCR（图像文字识别）能力、检索引用迁移 |
| 压缩包/训练素材 | 原包及必要成员、版本与标签 | 已采用训练样本目录与相应索引 | 选件解包与可重建范围确认 |

## 受控调用

在已有成功任务结果中读取 `artifactIds`（已发布的文件编号），由 BD AGENTS 明确调用：

```json
{
  "sourceTaskId": "原成功任务编号",
  "fileRefId": "该任务结果中的文件引用编号",
  "topic": "资讯",
  "purpose": "加工证据"
}
```

工具动作名称：`artifact.archive`（归档所选产物）。`confirmed`（已确认）表示**远端元数据一致**；`needs_review`（需要复核）表示远端结果未确定，后续只能沿冻结目标查证。

## 后续分批实施

1. 先验收实际百度网盘账号的不同来源产物，核对链接有效性、远端名称、大小、编号与同一对象复用。
2. 追踪各个来源任务的 `fileRefId`（文件引用编号）下游消费关系；使远端恢复能够恢复到当前受控任务，再允许更改本地引用生命周期。
3. 再取消网页重复 DOM、接口重复收据、视频音轨长期发布等不必要**长期**产物；保留任务失败与未决状态所需恢复证据。
4. 最后才对 `candidate_objects`（五步加工候选仓储）做无引用可回收判定，并验证 WFD 固定读回；不依据文件年龄或外部归档状态直接清理。
