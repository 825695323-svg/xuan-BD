# 逻辑维护与历史兼容边界

适用范围：BD（数据治理系统）的来源操作、AGENTS（会话代理）工具能力、固定计算入口、算法结果展示与页面偏好。这里规定维护位置，不增加运行时、数据库、任务状态或后台任务。

## 唯一管理位置

| 规则 | 维护位置 | 调用方职责 |
| --- | --- | --- |
| 新材料任务的单步能力与历史批量恢复 | `production-module-ports.ts` 的 `processingSessionContract()`（处理会话契约）及原 `PRODUCTION_MODULES`（八模块登记） | 会话能力和工具分组读取同一契约；不得另写 `execute: data.processing.run` 推荐新任务使用旧批量入口 |
| 来源操作可见目录、执行动作与工具选项 | `plugins/api-sources/operations.ts`（来源操作目录） | 旧请求仅做字段转换，再走同一目录和分派；供应商协议仍由各自适配器核对 |
| 来源主备连接资格 | `SourceSettingsService.assertOperationConnectionEnabled`（来源操作资格校验） | 历史备用校验调用同一实现；不能因为缺主源就追加未选账号或可选池 |
| 算法任务列表范围 | `LocalAlgorithmService.list(methodId?)`（按持久方法身份查询） | 方法筛选在 SQL 限页前完成；不以当前注册表否认旧方法的历史任务 |
| 算法任务读取与详情归属 | `algorithm-api.ts`（身份校验）及 `useAlgorithmResult`（只读详情状态） | 当前算法最近结果必须指定方法；切换、重复请求、卸载后的旧回执不能覆盖当前视图 |
| 对象默认选择与失效回落 | `useObjectSelection`（带目录就绪校验的选择状态） | 页面声明目录是否读齐以及是否默认第一项，不再自行加第二套回落副作用 |
| 设置保存 | `PreferencesProvider`（全局偏好管理器） | 即时保存页面不保留失效的手动保存、离页确认和虚构分区状态 |

## 新任务和历史任务分开

新计算只由现有 `algorithms.calculate`（AGENTS 算法调用）或同一计算模块的受信别名发起，输入仍须为真实 WFD（正式数据库）固定快照。`POST /processing/polars/tasks`（旧人工计算创建接口，相对工作区路径）返回 HTTP 410（入口已退役），错误码为 `ALGORITHM_AGENT_ENTRY_REQUIRED`（新计算必须由 AGENTS 工具发起），不创建任务，也不将旧请求静默转成另一类新任务。

历史任务查询、结果读取、原任务 `stage`（保管历史结果）和 `prepare`（按历史链路准备候选）继续保留。历史 `data.processing.run`（批量执行）仅在单独的 `legacyRecovery`（历史恢复能力）说明中呈现，仍由既有执行器拒绝不适用的新计划。`data.processing.recover`（核对原计划持久对象）仍可用于已有单步计划与历史计划，不创建新计划或重跑已完成步骤。不得删除或重写用户原件、原计划、任务身份、历史结果、采用记录及正式 WFD 清单/快照。

新 AGENTS 处理按既有八模块接口逐次读取反馈。固定算法产生的结构化派生结果经独立核对和既有 R1/WFD（正式交接与固定读回）路径处理，不再回到原报五步。历史采用记录用于诊断原记录与当前版本的关系，不是新计算的独立启用开关。

## 兼容必须是转换，而不是第二套业务

旧来源请求的 `apiOperation`（旧接口动作字段）和 `klineOperation`（旧行情动作字段）仍被接收，但统一转换为目录中的运行描述。混合两种动作、掺入另一种来源身份、提交未登记操作必须在创建任务之前拒绝。`source.fetch`（原件下载）中的官方网页与采集端点保留各自原始协议，不能伪装成行情操作。

移除未使用函数前要核对调用、类型与历史反序列化用途。不能只按“旧”字、文件名或导出次数删除 Pi（现用会话运行时标识）、DSH（旧凭据引用格式）、历史算法别名或历史任务解析器；这些属于单独迁移范围。

## 回归门禁

执行 `node scripts/logic-maintenance-check.mjs`（已清理模块未使用声明检查）以及 `npm run build`（类型检查与生产构建）。前者对登记的清理范围强制启用 TypeScript（类型系统）的未使用局部声明和参数校验；其他模块的历史告警会明确计数，但不被误报为本轮已清零。任何普通类型错误都导致失败，不能按“历史告警”忽略。

新增复用逻辑须带对应测试。至少覆盖：新旧请求分派相同、混合字段拒绝、主备资格不扩大、旧方法任务可读、方法筛选先于限页、迟到成功与错误隔离、A→B→A 往返选择、目录未就绪不回落、HTTP 410（入口退役）不创建任务、历史查询/恢复仍保留。

真实外部账号、模型、WFD 与 Polars（固定数据计算引擎）实证只在显式登记的隔离环境验证；没有凭据或解释器时列明跳过，不将单元替身当真实来源结果。
