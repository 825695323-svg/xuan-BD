# 来源原报分钟 CSV 整件交接

`source_minute_bulk_v1` 是现有 R1 分块入口的显式模式，使用同一材料服务、TaskService、R1 工作台运行时和 WFD 发布器。旧请求不自动切换模式，旧逐页任务及其固定回执继续按原协议恢复。

## 范围与数据含义

每次接收一个完整日 CSV，原件不超过 256 MiB、数据不超过 2,000,000 行。来源档案必须明确声明完整 11 列、一个日期轴、一个完整分钟标签和一个证券身份轴；所有原值均为文本，七个计量字段明确标记未知。名称列单独保存。空值与文字 `0`、`0.0` 分开，原件字节和原始行位置保留。

分钟标签只形成 `Asia/Shanghai` 下的索引桶，不证明原行情的区间方向、交易时段覆盖、量额单位、复权含义或历史可得时间。产物是 `source_claim`（来源原报），不能取得标准行情计算资格。

新产品使用版本化的 `wfd.source-minute-key/1` 身份规则。记录键为 `source_minute_YYYYMMDD_` 加上规范 JSON 数组 `[原身份文本, 原完整分钟标签]` 的 SHA-256；排序采用身份、分钟的 UTF-8 字节序。旧产品的行键不重解释。

## 接口与提交边界

下列路径均位于 `/api/bd` 下，继续使用应用现有操作者、停止代次及本地请求保护。

| 请求 | 行为 |
|---|---|
| `POST /r1/batches/chunked/start`，`mode=source_minute_bulk_v1` | 冻结来源、11 列档案、目标连接、计划和完整原件身份 |
| `POST /r1/batches/chunked/:id/chunks/:offset` | 顺序接收原字节，单块最多 2 MiB，`x-bd-chunk-sha256` 指定块摘要 |
| `POST /r1/batches/chunked/:id/advance` | 按原编号完成保管、加工、检查和 WFD 暂存，或恢复原任务 |
| `POST /r1/batches/chunked/:id/commit`，`{manifestDigest}` | 确认已展示的整件加工清单后正式提交，继续全部固定读回 |
| `POST /r1/batches/chunked/:id/fixed-read`，`{pageSize,cursor}` | 对完成的固定关联读页，页长 1–200，不读取可变当前快照 |
| `POST /r1/batches/chunked/:id/reclaim` | 全量读回成功、原件仍可恢复时清理本件加工目录 |

`ready_to_commit` 表示整件检查和暂存就绪，尚未正式发布。只有实际回执、完整读回和小型关联证明均完成，才进入 `completed`。同一日期完整语义值和合同相同为全件重复；不同则全件冲突，不能部分插入、覆盖或改成另一请求号重试。

WFD 使用 `wfd.source-minute-batch/1` 的 `batch_begin`、`batch_put_chunk`、`batch_status`、`batch_finalize` 和 `batch_read_page`。运输片最多 512 个；默认每片最多 512 KiB、5,000 行，以适应实际进程帧预算。整个清单、行数及摘要核对后只激活一次。传输分片边界不进入产品语义指纹。

提交后响应丢失或中断时，查询原编号。只读状态核对持久提交意图和真实激活记录；若已激活而正式凭证尚未收齐，继续同号 finalize 完成收尾，不能换号重新发布。

## 原件与加工副本

宿主须明确采用独立、受管的 `bulk_csv` 目录。目录失联时不回退内部磁盘，不初始化替代目录。业务状态库只保存小型计划、清单、游标和关联，不保存全部运输字节或逐行正式数据。

原件在唯一固定文件位置顺序接收；文件同步后才持久确认偏移。完整 SHA-256、固定块摘要和目录同步通过后，状态库原子登记固化。这个边界不依赖文件改名，也不把 ExFAT 的时间戳当作可靠内容版本。局部读取核对覆盖块的摘要，完整流读取在结束时核对整件摘要。用户选中的外部文件不因此成为可删除的受管文件。

加工沿用来源语义投影和确定性检查，以有界分片排序后生成运输片及原行定位；单件加工暂存预算为 768 MiB。接收、加工和交接按实际设备叠加空间预算，保留至少 4 GiB 余量。原件在 `reclaim` 后继续保留，只删除该请求生成且绑定的加工目录。

## 固定读回与兼容

BD 固定读回整件所有行，逐项核对结果根、规范定义、四份独立合同及合同包、连续行号、排序、业务键、正式行版本和每个加工片的全部单元格摘要。每完成一个完整片才持久保存检查点，中断最多重读未完成的一片。检查点属于受信本机状态库，公开 API 不接收外部检查点；其公开摘要用于检测损坏或串用，不是防恶意改写本机状态库的签名。

关联只保存原件、冻结计划、固定快照、产品、日期、结果根、行数与核验摘要。需要行数据时使用有界固定读取，不把一个空的或截断的旧逐行关联数组冒充整件完成。

WFD 存储采用按产品、年份、日期定位的不可变内容根和紧凑 Parquet 文件。普通旧产品与分钟分区共享当前快照；普通写入继承分钟根，不把旧基线冒充真实 HEAD。普通写入不能修改新分钟产品。尚不理解索引闭包的全库操作须明确拒绝，具体范围见 WFD 的能力说明。
