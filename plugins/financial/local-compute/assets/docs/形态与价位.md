# 形态与参考价位

本模块将日频行情转换为布尔形态序列或数值参考价位。`kind="pattern"`（形态）有 16 个操作、16 个输出；`kind="level"`（参考价位）有 13 个操作、17 个输出。计算只使用请求内的行情、参数和标准库。

请求遵循根目录的数据契约：`version=1`，明确填写 `kind`（类别）、`operation`（操作）、`params`（参数），以及 `data`（内嵌数据）或 `data_file`（相对请求文件的数据路径）。`operation="all"`（全部）时，`params` 必须包含本类别的每个操作名，各值仍是该操作自己的参数对象。无参数操作填写 `{}`。未知、遗漏或类型错误的参数均拒绝；布尔值不能代替数值。

行情必须按日期严格递增，日频、单位、时区、复权状态和复权依据均须显式声明。基础列为 `timestamp`（日期）和正数 `close`（收盘价）；下表写出的附加列为该项必需列，不能缺失或为 `null`（不可用值）。涉及成交量时还须声明 `volume_unit`（成交量单位）。不补日期、不填零、不排序、不复权。`observations_are_consecutive=true`（输入观测连续）只描述所供序列，不验证交易所日历；“上一条”及各窗口均按所供日频观测计数。

不足的历史、未凑齐的完整窗口、尚未出现的缺口事件、缺少交叉前值都输出 `null`。充分观察后条件不成立才输出 `false`（假）。完整窗口包含当前条；简单移动平均采用 `full_window`（完整窗口初始化），前 `N-1` 条不可用。方法信息会明确写出初始化及窗口口径。

## 形态操作

下表中的参数数值只是可直接使用的显式例子，调用时必须填写。除规则注明的固定条数外，允许其他满足契约的参数数值。

| 操作与中文含义 | 参数示例 | 附加列 | 精确定义 |
|---|---|---|---|
| `morning_star`（早晨之星条件） | `{"body_window":5,"small_body_ratio":0.4}` | `open`（开盘价） | 当前窗口内实体绝对值的均值为 `A`。向前第2条为阴线且实体 `>A`；前一条实体 `<A×small_body_ratio`；当前为阳线且收盘高于向前第2条的开收均值。 |
| `evening_star`（黄昏之星条件） | 同上 | `open` | 向前第2条为阳线且实体 `>A`；前一条实体 `<A×small_body_ratio`；当前为阴线且收盘低于向前第2条的开收均值。 |
| `hammer`（锤子线条件） | `{"recent_window":10,"lower_body_ratio":2,"upper_body_ratio":1}` | `open,high,low`（开、高、低价） | 全幅 `>0`、下影 `>实体×lower_body_ratio`、上影 `<实体×upper_body_ratio`，且当前低价等于包含当前条的窗口最低价。 |
| `bullish_engulfing`（看涨吞没） | `{}` | `open` | 前一条阴线、当前阳线；当前开盘严格低于前收，当前收盘严格高于前开。边界相等不算吞没。 |
| `three_rising_bullish`（三连阳且收盘递升） | `{}` | `open` | 最近三条均为阳线，三条收盘价严格递升。 |
| `three_falling_bearish`（三连阴且收盘递降） | `{}` | `open` | 最近三条均为阴线，三条收盘价严格递降。 |
| `gap_up`（向上跳空） | `{}` | `high,low` | 当前最低价严格高于前条最高价。 |
| `gap_down`（向下跳空） | `{}` | `high,low` | 当前最高价严格低于前条最低价。 |
| `volume_breakout`（放量且窗口收盘新高） | `{"volume_window":5,"volume_multiplier":2,"price_window":20}` | `volume`（成交量） | 当前成交量严格大于含当前条的均量乘倍数，且当前收盘 `>=` 含当前条的窗口最高收盘。 |
| `ma_bullish_alignment`（均线多头排列） | `{"windows":[5,10,20,60]}` | 无 | 四个窗口必须为严格递增的正整数；对应简单均价依次严格递减。 |
| `ma_bearish_alignment`（均线空头排列） | 同上 | 无 | 对应四个简单均价依次严格递增。 |
| `macd_cross_up`（平滑差上穿信号线） | `{"fast_window":12,"slow_window":26,"signal_window":9,"init":"first_valid"}` | 无 | 快慢指数均价之差为差值，差值的指数均值为信号线；当前差值 `>` 信号线且前条差值 `<=` 前条信号线。 |
| `macd_cross_down`（平滑差下穿信号线） | 同上 | 无 | 当前差值 `<` 信号线且前条差值 `>=` 前条信号线。 |
| `long_upper_shadow`（长上影线） | `{"body_multiplier":2}` | `open,high,low` | 全幅 `>0` 且上影严格大于实体绝对值乘倍数。实体为零而上影为正时成立。 |
| `return_up_threshold`（上涨幅度阈值条件） | `{"threshold_pct":5}` | 无 | `(当前收盘−前收)/前收×100 >= threshold_pct`。阈值按百分数填写，5 表示 5%。 |
| `return_down_threshold`（下跌幅度阈值条件） | 同上 | 无 | `(前收−当前收盘)/前收×100 >= threshold_pct`。 |

星形条件中 `A` 的锚点是**当前条**，不是前两条当时各自的均值。锤子线只核对表内形状与近期最低价条件；不另加下跌趋势。跳空只比较相邻两条，不追踪后续回补。放量窗口也包含放量的当前条。

指数均值的 `init="first_valid"`（首个有效值初始化）必填：第一条有效值直接作为种子，后续递推 `E=α×当前值+(1−α)×前值`，`α=2/(N+1)`。实现使用等价式 `E=前值+α×(当前值−前值)`，避免常量输入的数值漂移。差值和信号线采用同一初始化规则。因此交叉首条为 `null`，从第二条起有交叉判断依据。快窗口必须小于慢窗口。本模块没有窗口开始前的递推状态；更早历史会影响首段结果，方法信息会披露这一点。本模块拒绝 `state`（外部状态）字段，避免把批计算误当成状态续算。

上涨、下跌阈值只表示价格变化条件，**不识别真实交易所涨跌停**。规则没有板块、特殊处理、日期制度、最小报价单位或限价舍入信息；`threshold_pct`（百分数阈值）没有默认值，也不以某个示例阈值代表所有市场。

所有窗口为正整数；影线/小实体/量能倍数为有限正数；涨跌幅阈值为有限非负数。无额外趋势、缺口或量能筛选。

## 参考价位操作

| 操作与中文含义 | 参数示例 | 附加列 | 输出与定义 |
|---|---|---|---|
| `previous_high`（前条最高价） | `{}` | `high` | 前一条 `high`；首条为 `null`。 |
| `previous_low`（前条最低价） | `{}` | `low` | 前一条 `low`。 |
| `previous_close`（前条收盘价） | `{}` | 无 | 前一条 `close`。 |
| `highest_high_20`（20条最高价） | `{}` | `high` | 包含当前条的完整20条最高价。 |
| `lowest_low_20`（20条最低价） | `{}` | `low` | 包含当前条的完整20条最低价。 |
| `highest_high_60`（60条最高价） | `{}` | `high` | 包含当前条的完整60条最高价。 |
| `lowest_low_60`（60条最低价） | `{}` | `low` | 包含当前条的完整60条最低价。 |
| `pivot`（前条枢轴参考值） | `{}` | `high,low` | 五列：`pivot=P=(前高+前低+前收)/3`，`pivot_r1=2P−前低`，`pivot_s1=2P−前高`，`pivot_r2=P+前高−前低`，`pivot_s2=P−前高+前低`。 |
| `bollinger_upper`（布林上轨） | `{"window":20,"multiplier":2,"ddof":1}` | 无 | 完整窗口均价加 `multiplier×标准差`。 |
| `bollinger_lower`（布林下轨） | 同上 | 无 | 完整窗口均价减 `multiplier×标准差`。 |
| `latest_up_gap_previous_high`（最近向上缺口的前条高价） | `{}` | `high,low` | 向上缺口发生时记下前条最高价，此后持续输出最近一次记下的值。尚无缺口时为 `null`。 |
| `latest_down_gap_previous_low`（最近向下缺口的前条低价） | `{}` | `high,low` | 向下缺口发生时记下前条最低价，此后持续输出最近一次记下的值。 |
| `close_volume_mean`（收盘价按成交量加权的窗口均值） | `{"window":13}` | `volume` | `SUM(close×volume,N)/SUM(volume,N)`，输出单位沿用价格单位。完整窗口成交量之和为0时输出 `null` 并诊断。 |

布林标准差使用 `sqrt(SUM((close−窗口均价)^2)/(N−ddof))`；`ddof`（自由度调整）必须显式为0或1，且 `N>ddof`。两条轨道的窗口和倍数必须显式填写。`ddof=0`（总体式）与 `ddof=1`（样本式）均可复现，实际请求会保存在方法信息中。

缺口参考值遍历**所供全部历史**，不会在60条后自动失效，不对缺口回补作处理，不推测窗口开始前的缺口；输出名直接描述所记录的前条价格。参考值并不承诺仍然具有支撑或阻力效力。

收盘量加权均值只使用收盘价与成交量，**不是以真实成交额计算的成交成本**。本项不读取 `amount`（成交额），也不将它推算为已发生的真实成交额。

## 示例与验证

`examples/patterns`（形态示例）和 `examples/levels`（价位示例）中的每个操作均有正常请求、错误请求和实际核对的预期关键值。共用数据明确标为合成数据，包含各形态的成立和不成立实例。错误例用于证明必需字段或参数缺失会被拒绝；短历史的 `null` 是可接受输出，不是错误。

可在根目录运行：

```sh
python3 calculate.py --request examples/patterns/morning_star.normal.json
python3 calculate.py --request examples/levels/pivot.normal.json
python3 verification/patterns_levels_verify.py
```

验证脚本包含人工指定的形态正反例、完整窗口和严格边界检查、用独立公式复算指数递推及交叉、用标准统计函数复算布林轨、枢轴恒等式、缺口超过60条后的保留值，以及收盘量加权均值的独立核对。真实日线样本仅验证这些本地数值/布尔规则可执行且符合所述数学关系，不证明形态预测能力或交易有效性。
