# 扩展内置逐项契约

本文件是 `definitions/builtins.json` 与内置函数运行接口的机械投影，覆盖该定义中全部 **185** 个已登记内置操作（operations），每个操作一小节；不执行原有函数文本，不新增算法推断，不联网。

## 阅读约定

- arguments 参数数量：取自 operation 的 `argument_counts`，给出本实现允许的参数个数；字符串形式为原始记录，未在本文件解释。
- arguments 形式：数组元素须恰好为 `field` / `value` / `reference` 之一；`field` 须为所有观测行都存在的列名，`value` 须为标量，`reference` 须为明确关联字段名。
- parameters：内置调用不使用 `parameters`，`params` 仅接受 `arguments` 与 `method`。
- 必须 method 规则：取自 `required_policies`；`params.method` 必须显式给出这些键，`mode` 恒为必填，取 `causal_batch` 或 `retrospective_batch`。
- scope：取自 operation 的 `scope`，为既有登记值；本文件不做语义扩展。
- definition_note：仅当 operation 登记了该字段时列出。
- 正常样例：链接指向 `examples/builtins/<ID>.normal.json`（相对本文件的路径为 `../examples/builtins/<ID>.normal.json`）。
- 验收状态：本文件不做通过判定；统一以根 `扩展验证结果.json` 为准。
