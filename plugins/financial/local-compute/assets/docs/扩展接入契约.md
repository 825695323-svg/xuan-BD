# 扩展公式与内置函数接入

本文件说明现存计算资产的实现契约；[代码资产目录](../能力目录.json)不代表应用已放行全部操作，实际可调用范围以[受控登记](../../../../../modules/financial/algorithm-registry.ts)及当前采用状态为准。

公式与内置函数的源码入口沿用 [calculate.py](../calculate.py)（统一计算入口），`kind`（类别）分别为 `formula`（已登记公式）和 `builtin`（内置函数）。仅使用目录中已经保存的定义；请求不能传入待执行的公式文本。具体输入和参数见[公式逐项契约](扩展公式逐项契约.md)及[内置逐项契约](扩展内置逐项契约.md)。

## 公式请求

```json
{
  "version": 1,
  "kind": "formula",
  "operation": "H_01",
  "params": {
    "parameters": {"N": 5, "M": 10},
    "fields": {"CLOSE": "close"},
    "constants": {},
    "method": {"mode": "causal_batch"}
  },
  "data_file": "your-input/data.json"
}
```

上面是结构示意；实际参数键、范围和必需方法规则以当前已登记定义及逐项契约为准。`parameters`（数值参数）必须恰好覆盖登记键，范围也按登记定义检查，不自动套用旧默认值。登记默认值仍单独保留。`fields`（列映射）和 `constants`（常量）合起来必须恰好覆盖所需输入，不能重复绑定。常量必须给出 `value`（值）、`unit`（单位）和 `meaning`（含义），也不能代替尚未核实的业务事实。

`variant`（明示版本）用于16条各有两种计算正文的公式，必须显式选择 `level_1`（第一版本）或 `level_2`（第二版本）；这只选择定义，不能据此认定已有相应粒度的数据。

## 内置函数请求

`arguments`（参数数组）按位置给出，每项恰好是以下一种形式：`{"field":"close"}`（读取列）、`{"value":5}`（明确常量）或 `{"reference":"JLR"}`（供报告或关联序列查询的字段引用）。该操作允许的参数数量及规则见逐项契约。事实读取函数从提供的本地列取值，不会自动取得行情、财务、资金流或账户数据。

## 数据与口径

`data`（输入数据）至少包含 `metadata`（口径声明）和非空 `rows`（有序观测）。日线日期严格递增且唯一；其他观测时间必须包含与声明时区一致的偏移。窗口起止必须与记录相符。价格、量、额和其他列必须有明确单位或类型标签；数值必须有限。

日线四价仍遵守价格为正及高低价关系约束。量额可以为零，缺值必须保留为空，不能默认填零。字段绑定和算式能够运行不证明字段经济含义正确；金额、数量、比率或证券类别不匹配时不能把输出作为业务结论。一个股票日线计算样例也不证明同名基金、指数、分钟或实时业务已经验证。

金额除成交量形成价格的9项公式有额外单位约束：金额必须为元；正文含100倍换算的两项要求量为手，其余要求量为股，价格为元/股。样例显式使用相应换算列；不会把万元/手直接当成元/股。各项约束记录在定义的 `unit_requirements`（输入单位要求）中。

数据可额外提供三种显式上下文：

| 数据块 | 必须提供的内容 | 查询边界 |
|---|---|---|
| `related_series`（关联序列） | 以真实声明标识为键，每项包含口径、观测和字段映射 | 同频同区，按相同观测时间对齐；缺时点返回空，不沿用最近值 |
| `reports`（报告记录） | 主体、字段、报告期、报告类型、带时区可得时间、值和单位 | 值可为数值、文本或空；每个时点只使用已可得版本，修订不能改写更早观测的选择 |
| `memberships`（成员关系） | 主体、分组、名称、分类、生效起止和可得时间 | 按所给区间及可得时间判断；必须声明成员集合是否完整，不把未知当作不属于 |

报告查询同时要求 `observation_time`（日线查询时刻）及 `report_anchor`（报告选择基准）；基准为 `latest_period`（最新报告期）或 `latest_publication`（最新披露）。报告类型1、2、3、4分别对应一季、半年、三季、年度。年度和半年度读取可用年份或倒数序号；具体参数数量按逐项契约。本地上下文契约不代表现有数据库字段已完成这些接入。

`C_03` 和 `MMYJ` 用历史长度推断上市时间，因此额外要求 `metadata.history_starts_at_listing=true`（从上市首条观测开始）。近期截取窗口不能满足这个条件；输入须如实声明完整上市历史，不能将实际股票近期样本冒充完整上市历史。

“当天差”按明确交易日计算当前值减前一观测值，使用 `metadata.trading_day_field`（交易日列名）分组，不能直接用日线代替。`day_start=unknown`（日首未知）保留首条空值；只有显式声明 `sessions_start_complete=true`（各交易日从起点完整提供）时，才可选择 `zero_if_complete`（完整起点使用零基准）。交易日与日历日期分别声明，跨日差额不会混入下一交易日。原式中的区间累计仍以所供窗口为范围，不擅自改成每日清零。

统计区间起止指所供窗口，区间终点只能在整段回看模式使用。上涨/下跌趋势比率从明确完整成员集的现价及基准价格计算。位图函数只返回显式图像引用和锚点，不读取文件。成交笔数函数的缺计数返回零、结算字段空时回退到昨收，都是这两条明示定义的分支，不能推广为其他字段的默认补值规则。

## 计算规则

`method`（方法规则）逐项显式传入。主要约定如下：

| 规则 | 本地定义 |
|---|---|
| 初始化 | `first_valid`（首个有效值）用于递推；开始后的缺值使后续递推保持未知，不擅自重置种子 |
| 完整窗口 | 未凑足所需历史返回空；原式固定长窗口保留该长度，不用短窗口结果冒充 |
| 累计起点 | `observation_start`（所供观测起点），不等于上市起点或全年起点 |
| 标准差与协方差 | 明确 `ddof`（自由度修正）0或1；偏度和峰度另明确总体或样本估计 |
| 序列引用 | 正整数回看；负下标语义未确认的定义不开放。除零、缺值及未定义分支结果保持空 |
| 空值比较 | 只有明确的空值字面比较使用 `null_comparison=identity`（空值身份判断）；普通未知值不默认等于零 |
| 字符串 | 明确小数位和舍入方式；位置从1开始，未找到返回0。不会把字符串解释成代码 |
| 转折 | 单一开高低收序列、明确阈值及并列规则；只有确认后的转折可得，未确认末段省略 |
| 图形 | 返回文字、线段、颜色或锚点描述；没有恢复原画图软件的渲染、像素样式及外部位图 |

`causal_batch`（按所供观测顺序计算）不允许未来引用和回写。`retrospective_batch`（整段回看计算）才允许 `REFX`、`BACKSET`、转折回画等规则，结果保守标为整段末时点可得。转折标记另带锚点时间及确认时间。调用者不能将回看结果提前用于历史时点的决策。

这是完整批输入接口，不接受不完整的递推状态。返回 `method`（方法说明）、逐条值、空值诊断及必要的图形描述。`execution_executed=false`（未执行交易）始终成立；买卖标签仅为规则结果。

本地明确约定使计算可重复，不代表所有旧软件的隐含初值、默认枚举、修订方式和绘图效果逐项等价。固定比例参考价不代表现行交易所涨跌停价，规则输出的预设评价文字也不构成已验证的预测效果。
