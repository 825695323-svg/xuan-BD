# 站点采集源

`createCaptureSourcePlugin` 按 `CAPTURE_SOURCE_IDS`（已登记站点清单）与 `CAPTURE_SITE_RULES`（固定脚本清单）装配采集操作，复用应用的 `direct`（确定性运行时）任务、权限、原副作用身份和文件引用。站点采集与基础 `browser.control`（原始网页读取）分别装配，使用各站专属的浏览器登录态。

| 动作 | 固定操作 | 读取范围 |
| --- | --- | --- |
| `capture.bilibili.read` | `video-info`、`comments`、`search`、`popular`、`trending` | 视频简介与选定一页评论；选定页视频检索、热门视频榜与热搜关键词榜 |
| `capture.wechat.read` | `article` | 明确公众号链接的页面正文、图片原属性与链接位置 |
| `capture.xiaohongshu.read` | `note`、`comments` | 本站页面运行状态、页面自用读型接口及选定笔记或当前评论页 |
| `capture.weibo.read` | `comments`、`mobile-comments`、`hot` | 网页与移动网页的站点自用评论接口；热搜榜（移动端固定元数据名为 `m_weibo/comments`） |
| `capture.zhihu.read` | `hot`、`question` | 知乎热榜；网页自用问题与回答接口，原脚本仅返回回答预览 |
| `capture.google.read` | `search` | 浏览器搜索页面请求及结果、摘要提取 |
| `capture.eastmoney.read` | `guba-list`、`guba-post`、`news` | 东方财富股吧帖子列表（标题、作者、阅读、评论、时间）与单帖正文；选定页7×24快讯标题、摘要、时间和原文链接，不取行情 |
| `capture.xueqiu.read` | `hot`、`post` | 雪球热门讨论列表；单条讨论正文与回复；需要本站有效登录态，风控或未登录明确返回提示 |
| `capture.douyin.read` | `hot` | 本次选择条数内的热榜词条、热度和链接 |
| `capture.baidu.read` | `hot` | 本次选择条数内的实时热搜词条、热度、标签、摘要与链接 |
| `capture.sogouwechat.read` | `search` | 选定页文章标题、公众号、发布时间、最多200字符摘要及检索链接，不代表文章全文 |

微信、小红书与 Google 没有加入热榜：微信没有不需要登录的公开热榜；小红书的社区流要依赖页面内部 store 与签名，属另一类高风险脚本；Google 没有社区动态。三者维持原有取数方式。

`xueqiu` 的脚本改写自社区 bb-sites 适配器，按本工程合同重写：只保留只读请求、参数封闭、逐请求核对固定路径，上游许可状态沿用 `NOASSERTION`（无法断言许可），接入前未取得新许可。`eastmoney` 股吧两项为本工程自行编写，数据取自服务端渲染页面内嵌的列表与正文，不额外发起接口请求。

`sites.ts` 固定脚本名称、摘要、参数边界和读型请求范围，每次调用核对源码与元数据。网页自用接口属于本站采集内部步骤，不构成独立公开 API（接口）产品。模型只能提交已登记的操作参数。

[session.ts](session.ts)（站点会话服务）按已登记站点清单保留分别隔离的原生账号目录及采集模式。当前[会话路由](../../apps/server/capture-source-routes.ts)提供状态读取，以及用户显式打开登录、确认保存和取消登录；状态及控制由[来源页面](../../apps/web/src/ui/CaptureSourcesPage.tsx)调用。公开站点按登记进入 `public`（仅公开）模式，需登录站点使用 `saved`（已保存）模式；失效、未选择及未知状态继续阻断。程序不代填凭据、不自动登录或重放任务，远端有效性按站点实际响应记录。

每次采集沿原任务核对文件、网络、秘密及产物权限，并使用 `networkIsolation: intercept-only-proxy`（仅拦截代理联网）配置。请求按受审读取范围和原网络权限核对公网目标；页面内容策略限制表单提交、子框架、后台脚本、媒体和 WebSocket（双向网页连接）。取消或关闭结果未知时保留原任务和现场待核，不自动重放。

正文、选中评论和来源定位按原文件权限发布为新产物；模型只获得明确字段白名单的有界、脱敏预览。原始网页响应、脚本结果和页面原件保存在宿主保护的 `privateArtifactRoot/<task.id>/`（当前任务证据子目录），保留原字节摘要及完整性记录。证据引用绑定原任务，不进入可分享产物列表或模型预览，普通文件读取和转换不能访问。密码与验证码输入表单原件不保存，缺失原件会明确标记为部分证据。

微信图片保留原 `href`（链接）、`data-src`（延迟图片源）等属性及 DOM（文档树）位置，不下载或识别图片。B站只有带明确有效BV编号的 `video-info`（视频简介）和 `comments`（视频评论）操作提供 `video.transcribe_url`（公开视频转录）可接收的视频页面引用，视频简介与转录分别处理。转录、转换和 OCR（文字识别）继续调用现有固定能力。

评论动作只覆盖选定页；Google（谷歌搜索）摘要和知乎回答受脚本预览范围限制，不能称为完整原文。小红书需要本站有效页面状态及访问资格；带访问令牌的用户链接尚缺安全凭据引用，明确拒绝，不把令牌写入普通任务参数。登录、验证码、部分完成、失败和未知关闭分别记录。本站不清洗、纠错、生成特征、提交数据库或定时重采。

上游来源许可标记为 `NOASSERTION`（无法断言许可）；历史原句与来源引用见工程外指导索引中的归档记录。
