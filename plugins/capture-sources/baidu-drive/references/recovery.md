# 结果核对与续跑

| 状态 | 下一步 |
|---|---|
| 查询明确失败 | 保留错误类别，有限退避后重试；不能记为无结果或无更新 |
| 转存已受理 | 保存任务标识与目标目录，继续有限查询；不重复提交 |
| 写操作返回前中断 | 先查原目标和已有记录，不能靠本地退出状态判断是否生效 |
| 下载失败 | 核对已有文件和可续接状态，复用已确认的云端成果 |
| 本地大小或摘要不符 | 保留异常文件和证据，不称为完成，不自动删除云端来源 |
| 清理失败或没有清理能力 | 保留中转对象和关联记录，报告待处理 |

查询目录时若只返回目录自身，不能把它当成期待文件，也不能据此确认转存失败。核对路径、名称、文件类型、大小和分页完整性；真正的错名、多文件或不明内容须停止该件。

服务非零 `code` 或 `errno`、`success:false`、失败状态或有效错误字段均需处理，即使进程退出码为零。错误与发生阶段一起记录，不凭一个数字认定账号权益或擅自购买、重登、改网络。

只读查询及确认可重复的下载最多三次有间隔尝试，优先遵循服务退避信息。已有运行仍在进行时接续同一运行，不并发启动第二个实例处理相同目标。

清理前确认对象由本任务创建、对应成果已核验持久保存、实际授权覆盖该对象且当前宿主提供删除能力。只删精确中转对象，不清空共享父目录。结果不明、来源不明或仍含未知文件的目录保留。

本地SHA-256证明取得的字节；远端摘要字段须有明确算法和语义才能用于一致性比较，不把任意字符串当标准MD5（摘要算法）使用。
