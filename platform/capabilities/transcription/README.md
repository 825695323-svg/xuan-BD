# 内置音视频转录

本地文件转录与公开视频文字提取是平台固定能力，不依赖独立技能、可选插件或单独启用开关。`local.ts` 供个人动作和材料适配器共用，`video.ts` 处理明确请求的单个 YouTube（视频平台）或哔哩哔哩公开视频，优先字幕，缺少字幕时使用随包本地语音识别资源。`network.ts` 只提供受控视频提取的临时网络隧道。

工具与语音模型由宿主按应用资源清单绑定；缺失时明确不可用，不搜索系统工具、自动下载或换用云端识别。归属内置不增加文件、网络、执行或分享权限。每次调用保留原任务、源文件引用和摘要、真实时间段、文字产物及原生证据引用；不按文字长度编造时间轴。

本地转录执行上限为 256 MiB（268435456 字节），实际时长不超过一小时；网页附件与材料保管仍受各自入口上限约束。公开视频不处理登录受限内容、直播、播放列表或分段流。音轨转录不等于视频画面识字，也不等于正式业务入库。

调用入口为 `audio.transcribe`（本地文件转录）、`video.transcribe_url`（公开视频文字提取）及材料流程中的 `material.transcribe`（材料转录）。取消使用核心原任务信号；进程、网络或产物状态未确认时保留暂存和原副作用待核，不换编号重放。真实识别结果未经核听，不宣称逐字准确。原始来源保存在工程外[来源记录](../../../../../xuan%20harness/资料与历史/说明与记录/运行框架/施工记录/单环境与工程整理-20261019/source-provenance/transcription/DSH-SKILL.md)。
