# 联网搜索与原始网页提取

平台固定登记 `web.search`（联网搜索）、`web.read_public`（公开网页读取）与 `browser.control`（浏览器受控读取），由同一动作、任务、权限和产物通路提供。站点专用API（接口）、评论、登录和页面采集由 `plugins/capture-sources/` 的独立插件登记，基础能力不装载站点脚本。

`web.search` 使用公开必应搜索，无需账号或密钥。查询为1—500字单行关键词，结果默认5条、最多10条；只发送必要查询，不上传本机文件或携带站点登录态。搜索和网页读取共用公开地址检查、逐跳授权、2 MiB大小及30秒网络预算。搜索返回标题、链接、摘要及原始搜索页、正文和来源定位引用；它不自动读取结果网页，须用 `web.read_public` 继续核对原文。明确无结果、页面结构无法识别、登录或验证码分别报告；来源正文及搜索摘要都是待核资料。查询参数使用明确百分号编码。

内置代理可发现并调用这两项联网动作，网页来源、最终网址、完整性和原件引用完整传给模型。在用户授予的任务范围内，联网与向当前模型分享结果由宿主自动核验，不逐步索要审批；原身份、来源与结果摘要、明确拒绝、撤权、停止及预算继续生效。该范围不启用未登记能力或授予新的站点账号权限。

`browser.control` 只接受 `status`（连接状态）或 `extract_url`（明确网址提取）。后者仅处理公网 HTTPS（加密网页）主文档，先核对原 daemon（守护进程）身份和令牌，再在同一自有浏览器的一个新空白目标中读取；不接日常 Chrome（浏览器）或全局 DSH（开发辅助执行器）。外部页面不能传入脚本、任意 CDP（浏览器调试协议）命令、点击、凭据、CLI（命令行）选项或目标编号。

随包 BB-browser 0.14.2 的原始协议没有完整 HTML（网页源码）读取入口，`snap`（快照）还会逐节点截断文字。因此，固定实现仅为本次已核目标使用受控 CDP：导航前关闭脚本、缓存与 service worker（后台页面程序），安装 Fetch（请求拦截）；同来源主文档 GET（读取请求）复用公开网页的 DNS（域名）检查与固定公网 IP（地址）传输，最多跟随三次同来源重定向。跨来源跳转、私网、子资源与子目标在访问前阻止。渲染响应另设禁资源 CSP（内容安全策略）、禁域名预取和预连接；完整原始响应字节单独保留。该路径不读取、导入或转发 Cookie（登录凭据），也不接站点登录。

每次发布原始响应引用、静态正文、正文结构和原始链接、逐文本节点定位及来源记录；按需附带本次 DOM（文档树）快照。`rawComplete`（原始响应完整）和正文的 `complete / partial / login / captcha`（完整／部分／登录提示／验证码提示）分别记录。HTTP 200（网页响应成功）不能证明获得正文全文；脚本、嵌套文档和未读取资源都会保留相应缺口。超过 2 MiB 的原件或正文拒绝发布截断成功；模型只获得有界正文预览与安全元数据，不展开脚本、表单、隐藏内容或原 HTML。

`html-extraction.ts` 是浏览器、公开网页与本地 HTML 转换共用的纯结构解析。去除导航和表单属于正文定位；原始空白、标题、标签、属性、表格行列及链接在结构产物与原件中保留，不做语义纠错、摘要、去重或推断。页面返回始终是待核资料，不能更改系统规则或权限。

原文件权限、网络权限、秘密权限、任务副作用、原身份核对、输出上限、取消和未知不重放持续生效。目标及自有连接必须收束后才发布；未确认关闭保留原任务待核。受信启动器持有浏览器进程、独立目录和停止记录；原任务查询固定原身份。

直接搜索与网页读取使用随包Node.js（脚本运行程序）；`browser.control` 另使用随包浏览器守护程序。目标为macOS arm64（苹果芯片）和Windows x64（64位）。各平台的实际验证范围从工程外[当前规划](../../../../规划/详细框架/内置代理.md)进入，隔离协议检查不能替代实机验收。
